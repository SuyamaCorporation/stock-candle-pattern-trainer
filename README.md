# Candlestick Chart Pattern Recognition Trainer

## 概要
ランダム生成のローソク足チャートを表示し、ハンマー・陽の包み足・三羽烏などのパターンを択一クイズ形式で当てる教育ゲーム。

## 機能
- 8種類のローソク足パターン（ハンマー・シューティングスター・陽の包み足・陰の包み足・同時線・三羽烏・明けの明星・逆ハンマー）
- ランダム生成チャート（10本のローソク足）のcanvas描画
- 4択クイズ形式
- 正解・不正解フィードバックと解説表示
- スコアと連続正解数（ストリーク）の記録
- パターンガイド一覧

## 使い方
表示されたローソク足チャートのパターンを4つの選択肢から選んでください。正解すると解説が表示されます。「New Chart」ボタンで新しい問題に進めます。
